# Architecture Summary

## Folder Structure
- `src/` - Contains application source code
  - `routes/` - API route definitions
  - `models/` - Data models and state management
  - `services/` - Business logic services
- `tests/` - Test files
- `progress/` - Learning progress and evidence

## Data Models
- `users` - Array to store user data
- `teams` - Array to store team data
- `invitations` - Array to store invitation data

## API Routes
- `GET /health` - Health check endpoint
- `GET /teams` - List teams endpoint

## Authentication
This is a starter workspace without authentication implemented yet.

## Database
This is a starter workspace using in-memory arrays for data storage. No database connection configured yet.
