System Design Module 03: URL Shortener App Foundation

Artifact: URL shortener application with FastAPI backend
Location: api/app/main.py
Features:
- POST /shorten - Creates short URL from long URL
- GET /{short_code} - Redirects to original URL
- Redis caching for performance
- PostgreSQL database for persistence
- Celery background tasks for cleanup

Evidence: The application is implemented in api/app/main.py with full CRUD operations for URL shortening.
