# Module 2 Reflection: Technical Writing

## Comprehension Questions

1. **What core problem does this module solve in technical writing fundamentals?**
   This module solves the problem of technical writing that fails the reader - specifically, documents with buried ledes, undefined jargon, passive voice hiding accountability, poor structure, and wordiness that wastes the reader's time.

2. **Which decision in this module has the biggest impact, and why?**
   The structure decision (top-down vs bottom-up) has the biggest impact because it determines whether busy readers can quickly get the key information they need. Top-down structure respects the reader's time by putting the conclusion first.

3. **What evidence proves the implementation works end-to-end?**
   The rewritten document (rest_to_graphql_migration_rewrite.md) demonstrates the implementation works: it has the key decision in the first sentence, defines all acronyms (FE, BFF, GraphQL, SDK, SRE), uses active voice, has scannable headings, and reduced word count by 49% (from ~350 to 180 words).
