# Module 5 Reflection: Stakeholder Communication

## Comprehension Questions

1. **What core problem does this module solve in stakeholder communication?**
   This module solves the problem of engineers communicating technical decisions to non-technical stakeholders in a way that drives action. It teaches translating technical details into business impact, avoiding jargon, surfacing risks in plain language, and ending with clear asks.

2. **Which decision in this module has the biggest impact, and why?**
   The communication medium decision (written memo vs visual presentation) has the biggest impact because it determines whether the information reaches all stakeholders (memo scales) or allows real-time adjustment (presentation). Choosing the wrong medium can mean the decision never gets made because the right people don't see it or don't understand it.

3. **What evidence proves the implementation works end-to-end?**
   The rewritten infrastructure migration email (infrastructure_migration_fixed.md) demonstrates the implementation works: it opens with business impact (Black Friday slowdown), translates all technical terms to plain language (traffic routing system instead of Kong/NGINX), surfaces buried risk clearly (server resource validation), and ends with specific asks (2 engineers for 8 weeks, roadmap alignment, load test timing).
