# Module 4 Context: Postmortems & Blameless Culture

## Micro-Exercise Answers

1. **Remember a mistake you made - did anyone ask "why did the system allow that?" or "why did you do that?" What was the difference in your response?**
   When I accidentally deleted test data in a shared database, my lead asked "why did the system allow destructive commands without confirmation?" instead of "why did you do that?" The difference: I felt safe to explain the technical gap (missing safeguards) rather than defensive about my actions. I focused on fixing the system, not defending myself.

2. **If you knew you would be punished for reporting a bug you introduced, would you report it? What if nobody else had noticed yet?**
   If punishment was certain, I would not report it if nobody else noticed. I would try to fix it quietly. This is dangerous because the bug might affect others before I can fix it, and the team loses learning opportunities from the incident. Blameless culture is not just nice - it's a safety mechanism for the system.
