# Module 1 Pretest Answers

## Part A: Quick Setup Check

- OS: Windows, Shell: PowerShell
- Tools: Node.js, git, and VS Code are installed and ready

## Part B: Starting Questions

1. **Self-rating:** ok (I can break work into tasks but sometimes miss dependencies)

2. **First thing before writing code:** Read the spec thoroughly to understand requirements, identify edge cases, and note any ambiguities.

3. **Build order:** A, B, C, D (C depends on A, D depends on B and C)

4. **Vertical slice:** A working end-to-end feature from UI to database that delivers real user value. Build one first to validate architecture and get early feedback.

5. **Mid-sprint new requirement:** Assess impact on current work, communicate with stakeholders to re-prioritize, and adjust the sprint plan if necessary.

6. **Planning philosophy:** "Plan enough to start, then adapt" - requirements change and you learn by building, so over-planning wastes time.

7. **Good task description:** Clear acceptance criteria, dependencies listed, and enough context for someone to understand why and what without asking questions.

8. **Shared database table discovered mid-build:** Stop, assess the impact on both tasks, add a dependency between them, and communicate the change to the team.
